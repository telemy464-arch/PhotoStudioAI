## ✨ মূল সুবিধাসমূহ (Key Features)

1. **১০০% লোকাল অফলাইন এআই পেন-কাট (`rembg u2net`):**
   - ফটোশপ ছাড়া কোনো ইন্টারনেটের সাহায্য ছাড়াই মানুষের চুল, কানের কোণ ও কাঁধ নিখুঁত রেখে সেকেন্ডে ব্যাকগ্রাউন্ড রিমুভ ও যেকোনো স্টুডিও ব্যাকগ্রাউন্ড (সাদা, ব্লু, স্কাই-ব্লু, গ্রে) পরিবর্তন।

2. **অটো ফেস এলাইনমেন্ট ও স্ট্রেইটেন (ICAO 9303 Standard):**
   - মিডিয়াপাইপ এআই দিয়ে মুখ শনাক্ত করে বাঁকা ছবি স্বয়ংক্রিয়ভাবে সোজা করা হয় এবং আন্তর্জাতিক মাপ অনুযায়ী ৭০-৭২% হেড সাইজ ও ৩.৫ মিমি টপ মার্জিন বজায় রেখে পাসপোর্ট ও স্ট্যাম্প সাইজ ফ্রেম করা হয়।

3. **অনলাইন এআই স্টুডিও অ্যাসিস্ট্যান্ট (Dola.com / Ultra HD Assistant):**
   - **ভাঙ্গা ও কাটা মুখ মেরামত:** ফাটা, কাটা, খামচি ও পুরনো ছবির জন্য ১ ক্লিকে পারফেক্ট প্রম্পট তৈরি।
   - **অফিশিয়াল স্যুট ও টাই / ব্লেজার / হিজাব:** ১ ক্লিকে আন্তর্জাতিক ড্রেস কোড প্রম্পট কপি।
   - **ইনগ্রেডিয়েন্ট মূল ছবি কপি/ডাউনলোড:** এআই পোর্টালে ব্যবহারের জন্য ছবি প্রস্তুত।
   - **অটো পাসপোর্ট ড্রপজোন:** এআই থেকে পাওয়া ছবিটি ড্রপ বা `Ctrl+V` পেস্ট করা মাত্রই সেকেন্ডে পাসপোর্ট ও স্ট্যাম্প সাইজ তৈরি!

4. **১-ক্লিক অটো আপডেট (Auto Update System):**
   - **অ্যাপের ভেতরেই অটো-আপডেট:** সফটওয়্যারের ভেতর থেকে এক ক্লিকে সরাসরি গিটহাব থেকে নতুন ভার্সনে আপডেট করার সুবিধা।
   - **ডেস্কটপ আপডেট স্ক্রিপ্ট (`update_app.bat`):** গিট ইনস্টল না থাকলেও সাধারণ ব্যবহারকারী ডাবল ক্লিকেই স্বয়ংক্রিয়ভাবে লেটেস্ট ভার্সনে আপডেট করতে পারবেন।

5. **প্রিন্ট ও PDF শিট জেনারেটর (300 DPI Studio Lab Quality):**
   - 4R (4×6") ফটো পেপারে ৪ কপি পাসপোর্ট বা ৮ কপি স্ট্যাম্প সাইজ।
   - A4 পেপারে ৮/১২ কপি পাসপোর্ট বা ১৬ কপি স্ট্যাম্প সাইজ।
   - কম্বো প্যাক (৪ পাসপোর্ট + ৬ স্ট্যাম্প)।
   - কাঁচি দিয়ে কাটার জন্য কাটিং মার্ক সহ সরাসরি প্রিন্ট ও ভেক্টর PDF এক্সপোর্ট।

## 🚀 কীভাবে চালাবেন (How to Run)

### পিসিতে চালানোর নিয়ম (On Windows PC):
- সরাসরি `run_app.bat` ফাইলে ডাবল-ক্লিক করুন।
- অথবা টার্মিনালে রান করুন:
  ```bash
  python server.py
  ```
- স্বয়ংক্রিয়ভাবে আপনার ডিফল্ট ব্রাউজারে `http://localhost:8000` ওপেন হবে।

## 🔄 ইউজার কীভাবে অটো-আপডেট করবেন (How Users Auto-Update)

ব্যবহারকারীরা দুইটি উপায়ে অতি সহজে সফটওয়্যারটি আপডেট করতে পারবেন:

### উপায় ১: অ্যাপের ভেতর থেকে (ইন-অ্যাপ আপডেট)
1. অ্যাপের উপরের হেডার বারে থাকা ভার্সন বাটনে (`v1.2.0`) ক্লিক করুন।
2. নতুন আপডেট থাকলে **"এক ক্লিকে আপডেট করুন"** বাটনে চাপ দিন।
3. স্বয়ংক্রিয়ভাবে নতুন ফাইল ডাউনলোড হয়ে ২ সেকেন্ডে পেজ রিলোড হবে।

### উপায় ২: ডেস্কটপ স্ক্রিপ্ট দিয়ে (১-ক্লিক আপডেট)
1. ফোল্ডারে থাকা `update_app.bat` ফাইলে ডাবল-ক্লিক করুন।
2. স্বয়ংক্রিয়ভাবে গিটহাব থেকে সর্বশেষ কোড ও ফাইল আপডেট হয়ে যাবে।

3. অথবা টার্মিনালে নিচের কমান্ডগুলো রান করুন:
   ```bash
   git add .
   git commit -m "PhotoStudio AI v1.2.0 - Auto Update & Studio Assistant"
   git push -u origin main
   ```

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)
- **Frontend:** HTML5, Tailwind CSS, Modern ES6 JavaScript, jsPDF.
- **Backend:** Python 3, Flask, rembg (u2net ONNX deep learning model).
- **Vision AI:** Google MediaPipe (Face Detection, Selfie Segmentation).
